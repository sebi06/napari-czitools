# napari-czitools v0.12.0

Release date: 2026-08-21

## Highlights

- Updated the plugin to align with `czitools>=0.20.0`.
- Clarified lazy-loading behavior in the reader and documentation.
- Fixed README rendering issues for PyPI by switching to absolute GitHub image URLs and current badge URLs.
- Expanded compatibility notes and contributor guidance for Python 3.12/3.13 and CI behavior.

## What Changed

### Dependency and compatibility updates

- Declared support for the current `czitools>=0.20.0` baseline.
- Updated README and contributor documentation to describe the current stack-oriented lazy-loading path and the distinction from true Dask-backed on-demand loading.
- Kept the CI and tox guidance in sync with the current Linux/Windows/macOS matrix.

### Documentation fixes

- Fixed README badges and image links so they render correctly on GitHub and PyPI.
- Added a user-facing explanation of the `Lazy Loading` checkbox and what happens behind the scenes.
- Removed outdated compatibility notes from earlier `czitools` versions.

## Validation

- Targeted test run passed in the workspace environment using the project test task.

## Notes

- This release is created from `main`.
- GitHub Actions publishes to PyPI when a version tag matching `v*` is pushed.

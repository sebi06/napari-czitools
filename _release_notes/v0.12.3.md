# napari-czitools v0.12.3

Release date: 2026-08-28

## Highlights

- The Advanced CZI Reader now always uses lazy multiscale loading, removing an
  unnecessary configuration choice from the normal workflow.
- The reader dock expands more naturally for wide metadata and remains aligned
  when single-position dimension sliders are hidden.
- The **Slider Type** selector stays above the metadata area when switching
  between table and tree views.
- Updated screenshots and documentation explain the current workflow and the
  effect of **3D preview size**.

## Loading behavior

The Advanced CZI Reader always requests lazy, Dask-backed, multiscale data.
Pixel tiles are loaded as napari needs them instead of materializing the full
selection in memory. Python callers can still select the eager path with
`use_lazy=False` when a regular in-memory array is required.

## Interface fixes

The dock can expand horizontally up to 8192 pixels, subject to the available
napari window width. Its controls remain top-aligned when metadata causes
single-position sliders to be hidden, and metadata mode changes no longer move
the **Slider Type** selector below the table or tree.

## Compatibility

- Python 3.12 and 3.13
- napari 0.7 or newer
- czitools 0.22.1 or newer

## Installation

```bash
python -m pip install --upgrade "napari-czitools==0.12.3"
```

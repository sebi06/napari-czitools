# napari-czitools v0.12.1

Release date: 2026-08-24

## Highlights

- Updated to require `czitools>=0.21.0` for improved compatibility and new features.
- Fixed lazy-loading behavior to ensure proper data streaming and display updates.
- Enhanced documentation with clarifications on usage patterns and lazy-loading mechanics.
- Added Mermaid diagram instructions for architecture and system documentation.

## What Changed

### Dependency updates

- Increased minimum required `czitools` version to >= 0.21.0 to leverage improved CZI reading capabilities and better metadata handling.

### Lazy-loading fixes and improvements

- Fixed a critical bug in lazy-loading implementation in `_io.py` and `_widget.py`.
- Refactored the lazy-loading logic in `_reader.py` for more reliable on-demand data streaming.
- Improved integration with Dask arrays to prevent unnecessary data loading and optimize memory usage.

### Documentation and infrastructure

- Enhanced `copilot-instructions.md` with updated guidance for contributors and maintainers.
- Added comprehensive Mermaid diagram instructions in `.github/instructions/mermaid.instructions.md` for better architecture visualization and documentation.
- Updated `README.md` with clearer explanations of lazy-loading behavior and its practical implications.

### Testing

- Added and updated tests in `_tests/test__io.py` to validate lazy-loading fixes.

## Notes

- This release is a patch release (v0.12.1) focusing on bug fixes and minor improvements over v0.12.0.
- The `Lazy Loading` checkbox behavior is now correctly implemented with proper Dask integration.
- All changes maintain backward compatibility with existing code and napari plugins.
- This release is created from `main`.
- GitHub Actions publishes to PyPI when a version tag matching `v*` is pushed.

## Validation

- Full integration tests passed in the development environment.
- Verified lazy-loading behavior with sample CZI files of varying sizes.

# napari-czitools v0.12.2

Release date: 2026-08-27

## Highlights

- Drag and drop a local `.czi` file onto **Select CZI Image**.
- Render large Z-stacks in napari 3D mode using texture-safe coarse pyramid
  levels.
- Configure and persist the **3D preview size** limit in the advanced reader.
- Requires `czitools>=0.22.1` for robust optional microscope metadata.

## 3D rendering

The default coarse pyramid edge is now 2048 pixels, which fits the broadly
supported OpenGL 3D texture limit. Files without a usable coarse level receive
a synthetic level through czitools. A one-level pyramid is passed as
single-scale data so napari can use its own downsampling fallback.

The advanced reader exposes **3D preview size** above **Load Pixel Data**. The
control becomes available after metadata is loaded, and its value is stored
across napari sessions. Python callers can override the same setting with
`max_coarse_edge` in `CZIDataLoader` or `reader_function_adv`.

## Compatibility

- Python 3.12 and 3.13
- napari 0.7 or newer
- czitools 0.22.1 or newer

## Installation

```bash
python -m pip install --upgrade "napari-czitools==0.12.2"
```

## Validation

- Loader and configuration tests pass.
- 3D rendering was verified with `NeuroSpheres_DCV_big.czi`; napari selected
  the generated `134 x 1104 x 1376` coarse level without a texture-limit error.

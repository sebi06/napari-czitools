# napari-czitools v0.12.4

Release date: 2026-08-28

## Hotfix

This release restores the intended `czitools>=0.22.1` package dependency.
Version 0.12.3 accidentally published metadata allowing `czitools>=0.20.0`,
which was inconsistent with the plugin's documented and tested requirement.

No runtime behavior changed from version 0.12.3.

## Compatibility

- Python 3.12 and 3.13
- napari 0.7 or newer
- czitools 0.22.1 or newer

## Installation

```bash
python -m pip install --upgrade "napari-czitools==0.12.4"
```

# napari-czitools v0.13.0

Release date: 2026-11-06

## Optional VZIP Loading

- Open CZI-derived VZIP reference archives through File > Open, canvas drops,
  or the Advanced CZI Reader. Normal CZI loading remains the default.
- Create archives in a background worker using the released
  `czitools.export_tools.create_czi_vzip` API. Choose a destination with
  **Save archive as...** and explicitly Reuse, Rebuild, or Cancel when an
  archive already exists.
- Preserve OME axes, physical scale and origin, channel colors and display
  windows, and stored pyramid levels without eagerly loading image pixels.
- Apply scene, time, channel, and Z selections only to displayed lazy layers.
  The archive continues to reference the whole CZI.

## Lazy Scene Stacking

- Stack compatible selected scenes lazily along a leading S axis, with one
  layer per channel.
- Keep incompatible scenes separate without cropping or resampling.
- Preserve original per-scene transforms in layer metadata; stacked scenes
  use local coordinates when their stage origins differ.
- Use one CZI/VZIP file selector, with archive-specific controls shown only
  when applicable.

## Fixes

- Require `czitools>=0.27.3` in the VZIP extra so creating archives does not
  require a development checkout. The core dependency minimum is unchanged.
- Constrain the testing extra to `pytest<9.2` to avoid Linux forked-test
  failures caused by report fields that pytest-forked cannot serialize.

## Compatibility And Limitations

- Python 3.12 and 3.13 on Linux, Windows, and macOS.
- Core dependency: `czitools>=0.22.1`.
- Optional VZIP dependencies: `czitools>=0.27.3` and
  `refkv[zarr,images]>=0.2.0`.
- VZIP stores references, not copied CZI pixels. The original local CZI must
  remain unchanged at its recorded location. Rebuild after modifying it;
  reuse does not fingerprint source contents.
- Only CZI-derived refkv archives with local sources are supported. Missing
  sources and unsupported archives produce explicit errors.
- VZIP loading uses stored pyramid levels only; it does not generate extra
  3D preview levels. Supported CZI layouts and compression depend on refkv.

## Installation

Standard CZI support:

```bash
python -m pip install --upgrade "napari-czitools==0.13.0"
```

With optional VZIP support:

```bash
python -m pip install --upgrade "napari-czitools[vzip]==0.13.0"
```
